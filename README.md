# 🛡 Smart Tourism Safety Grid

A React-based smart tourism safety platform designed to improve tourist security through digital identity, emergency assistance, safety monitoring, and tourist information services.

## 🚀 Features

- 🏠 Smart Tourism Home Page
- 📝 Tourist Registration
- 🆔 Digital Tourist ID
- 🚨 Emergency SOS System
- 📊 Safety Monitoring Dashboard
- 🛡 Safety Tips
- ☎️ Emergency Contacts
- 🏞 Tourist Attractions

## 🛠 Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Vite

## 🎯 Project Objective

To provide a digital platform that helps tourists travel safely by providing quick access to emergency services, tourist identification, and safety information.
